## Запуск проекта

Из командной строки: python main.py

## Описание 3-х проверок сценария

1. Слишком короткий ввод, менее 3 символов ввод

Вывод сообщения об ошибке: String should have at least 3 characters

2. Слишком длинный ввод, более 1000 символов

Вывод сообщения об ошибке: String should have at least 1000 characters

3. Нормальный ввод

Сколько лет живут черепахи

Ответ: Продолжительность жизни черепах зависит от их вида. Морские черепахи обычно живут около 30-50 лет, сухопутные — 50-100 лет, а некоторые крупные виды, например, гигантская слоновая черепаха, могут доживать до 150 лет и даже дольше.
